# Exercícios

**Exercício 1:** Faça um programa que leia um número inteiro e mostre a tabuada de 1 a 10.

**Exercício 2:** Faça um programa que leia um número inteiro. Esse número é a posição até onde a sequência Fibonacci será exibida.

**Exercício 3:** Faça um programa que leia um número inteiro e mostre primeiramente só os valores ímpares, de forma crescente e depois os valores pares, de forma decrescente. O número digitado é a condição de parada.

**Exercício 4:** Faça um programa que leia um número inteiro e mostre todos os números primos até ele, inclusive ele (caso seja primo).

**Exercício 5:** Faça um programa que leia um número inteiro e exiba o seu cálculo fatorial, retornando o seu resultado.
